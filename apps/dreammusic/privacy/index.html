Dream Music Player 개인정보처리방침

시행일: 2026년 9월 24일

Dream Music Player(이하 “앱”)는 사용자의 개인정보와 Google Drive 데이터를 보호하기 위해 이 방침을 제공합니다.

1. Google Drive 데이터 접근

사용자가 Google Drive 연결 기능을 직접 선택하고 Google 계정 권한을 허용한 경우, 앱은 사용자의 Drive에 있는 음악 파일과 폴더를 탐색하고 재생하기 위해 Google Drive 읽기 권한을 사용합니다.

이 과정에서 파일명, 폴더명, 파일 형식, 재생에 필요한 메타데이터 및 사용자가 재생하는 미디어 콘텐츠에 접근할 수 있습니다.

2. 데이터의 이용 목적

접근한 데이터는 음악 라이브러리 표시, 폴더 탐색, 검색, 앨범 정보 표시 및 음악 재생 기능을 제공하기 위해서만 사용됩니다.

3. 데이터 저장 및 공유

앱은 빠른 탐색과 재생을 위해 파일명, 폴더명, 파일 형식, 재생에 필요한 메타데이터와 연결 상태를 사용자의 기기에 저장할 수 있습니다. Google Drive의 파일 콘텐츠, 폴더 목록 또는 재생 데이터는 개발자의 서버에 업로드하거나 판매하지 않습니다.

Google Drive 데이터는 음악 탐색과 재생이라는 목적에 필요한 범위에서만 처리하며, 광고·프로파일링·제3자 제공 목적으로 사용하지 않습니다.

4. 공유 대상 및 제3자 제공

Google Drive 기능을 사용할 때 Google OAuth 및 Google Drive API 요청은 Google LLC로 전송됩니다. Google의 데이터 처리는 Google 개인정보처리방침과 해당 API 정책의 적용을 받습니다.

차량 라이선스 기능을 사용하는 경우에 한해 구매 계정 확인과 차량 라이선스 발급에 필요한 인증 정보가 라이선스 서버로 전송될 수 있습니다. 이 과정에서 Google Drive 파일, 폴더 목록, 파일 콘텐츠는 라이선스 서버로 전송되지 않으며, 차량 라이선스 인증은 Google Drive 음악 소스 로그인과 별개입니다.

5. 데이터 보호 방법

OAuth 인증과 Google API 통신에는 Google의 공식 OAuth 흐름과 HTTPS 연결을 사용합니다. 앱의 연결 상태와 음악 라이브러리 정보는 Android 앱 전용 저장공간에 보관하며, 앱은 Drive 파일을 생성·수정·삭제·이동·공유하지 않고 읽기 전용으로 처리합니다.

6. 보유 기간 및 삭제

Google Drive 데이터와 관련 로컬 캐시는 음악 탐색과 재생에 필요한 기간 동안만 기기에 보관합니다. 사용자는 앱에서 Google Drive 연결을 해제하거나 기기 설정에서 앱 데이터를 삭제하여 저장된 연결 정보와 로컬 라이브러리를 삭제할 수 있습니다.

차량 라이선스 인증 정보는 라이선스의 유효기간과 부정 사용 방지에 필요한 기간 동안만 처리하며, 차량 앱의 라이선스 관리 기능 또는 앱 데이터 삭제를 통해 제거할 수 있습니다.

7. Google API 데이터 사용

앱의 Google 사용자 데이터 사용은 Google API Services User Data Policy 및 Limited Use 요건을 준수합니다.

8. 제3자 서비스

Google Drive 기능은 Google LLC가 제공하는 Google OAuth 및 Google Drive API를 사용합니다. 해당 서비스의 데이터 처리는 Google의 정책이 적용될 수 있습니다.

9. 개인정보처리방침 변경

기능 또는 관련 법령의 변경에 따라 이 방침을 수정할 수 있으며, 변경 내용은 이 페이지에 게시합니다.

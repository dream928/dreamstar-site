📱 스마트폰 · 태블릿 사용 설명서

Android 휴대폰과 태블릿의 터치 화면에서 Dream Music Player를 사용하는 안내입니다. 화면 크기에 따라 세로·가로 배치가 달라져도 기능은 동일합니다.

목차
  • 빠른 시작
  • 음악 소스
  • 탐색과 재생목록
  • 동영상·가사
  • 설정과 문제 해결

1. 빠른 시작

  1. 앱 왼쪽 메뉴에서 소스를 누릅니다.
  2. 음악이 있는 저장 위치를 선택하고 스캔을 시작합니다.
  3. 음악, 아티스트, 앨범, 폴더 중 원하는 보기에서 곡을 탭하면 재생됩니다.

첫 스캔 중에도 먼저 준비된 항목을 볼 수 있습니다. 스캔 안내창의 OK(백그라운드 진행)을 누르면 나머지 탐색은 계속됩니다.

2. 음악 소스 연결

내장 저장소

소스 → 내장 저장소
휴대폰 또는 태블릿에 저장된 음악을 스캔합니다. 새 파일을 넣은 뒤에는 화면 상단의 다시 스캔을 누르세요.

USB 음악 폴더

소스 → USB 음악 폴더
Android 폴더 선택 화면에서 USB 또는 외장 저장소 안의 음악 폴더를 선택합니다. 선택 위치는 앱이 기억합니다.

Google Drive

소스 → Google Drive → Google 계정 로그인
앱은 Drive의 음악 파일과 폴더를 찾아 재생하기 위해 읽기 전용 권한을 요청합니다. 업로드·수정·삭제 권한은 요청하지 않습니다.
  • 로그인 후 폴더를 직접 열거나 전체 라이브러리를 스캔할 수 있습니다.
  • 파일이 많은 경우 첫 목록을 먼저 표시한 뒤 나머지 스캔을 백그라운드에서 수행합니다.
  • 로그인 만료 안내가 나오면 Google Drive를 다시 선택해 로그인합니다.

NAS WebDAV

소스 → 시놀로지 NAS WebDAV
표시 이름, 호스트, 사용자 이름, 비밀번호를 입력한 뒤 저장 및 스캔을 누릅니다. 필요하면 포트와 경로를 지정합니다.
  • 가능하면 HTTPS를 사용하세요.
  • 공인되지 않은 인증서 경고가 나오면 NAS 관리 화면의 SHA-256 지문과 정확히 일치할 때만 승인하세요.

3. 탐색과 재생목록

  • 아티스트·앨범·음악: 음악 파일의 태그를 기준으로 분류합니다.
  • 폴더: 실제 폴더 구조를 따라 탐색하고 파일명·제목·가수 순으로 정렬할 수 있습니다.
  • 검색: 현재 소스에서 제목 또는 가수명으로 찾습니다.
  • 즐겨찾기·재생목록: 자주 듣는 곡을 모으고 새 재생목록을 만들 수 있습니다.

스와이프 동작

  • 곡을 왼쪽으로 밀기: 지금 재생, 다음에 재생, 대기열 추가, 재생목록 열기
  • 곡을 오른쪽으로 밀기: 재생목록 추가, 즐겨찾기, 라이브러리에서 제거

라이브러리에서 제거해도 원본 파일은 삭제되지 않습니다. 앱의 색인 항목만 제거됩니다.

4. 동영상과 가사

동영상

동영상 메뉴가 표시되면 동영상 파일을 선택해 재생할 수 있습니다. Google Drive와 WebDAV에서는 같은 폴더의 같은 파일명 기반 자막을 선택할 수 있습니다.

가사

재생 화면에서 가사를 열면 곡명과 가수 정보로 온라인 가사를 조회합니다. 시간 정보가 있는 가사는 재생 시점에 맞춰 강조됩니다. 결과가 없으면 Google 또는 Naver 가사 검색으로 이동할 수 있습니다.

5. 설정과 문제 해결

  • 언어: 현재 한국어와 English 중에서 선택
  • 사운드: 20밴드 Pro Equalizer, ReplayGain 음량 정규화, Loudness 보정
  • 재생 환경: 이전 재생 위치 기억, 셔플 상태 유지, 다음 그룹 자동 이어 재생, 폴더 파일 정렬
  • UI 테마: 여러 색상 테마를 즉시 적용

연결 또는 파일 표시 문제

현재 소스를 확인한 뒤 다시 스캔을 실행하세요. USB는 연결 상태와 폴더 권한을, Drive와 NAS는 네트워크·로그인·주소 정보를 확인합니다. 계속 문제가 발생하면 고객 지원으로 기기 모델과 오류 메시지를 보내 주세요.
